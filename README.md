# mastering_leetcode

## Daily workflow

Every problem should follow this process.

### Step 1

Read the problem. Spend the following time without looking at hints:

- Easy: 15 minutes
- Medium: 30 minutes

### Step 2

If stuck, read only the hint—not the solution.

### Step 3

If still stuck, watch or read Carl's explanation.

### Step 4

Close the solution and write it completely from memory.

### Step 5 — One day later

Rewrite the solution again with no reference.

### Step 6 — One week later

Solve it again.

This spaced repetition is where real improvement happens. Many experienced candidates recommend emphasizing recall over simply accumulating solved problems.
